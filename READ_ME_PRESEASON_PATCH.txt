VCC PRESEASON PATCH

Replace these files on your website:
- admin.html
- vcc-ops.js
- match-room.html
- matches.html
- tournaments.html

Run this SQL in Supabase if you have not already:
- SUPABASE_VCC_OPS_ADDON.sql

Preseason mode appears in admin.html after unlocking admin access:
1. Open admin.html
2. Enter the admin code from ADMIN_CODE.txt
3. In Create/Edit Tournament, set Format = Preseason League Mode
4. Add teams in Teams/Seeds, one team per line
5. Save Tournament
6. Use the Preseason League Mode box to Generate Next Preseason Week

If you still don't see it, clear browser cache or hard refresh:
Windows: Ctrl + F5
Mac: Cmd + Shift + R
