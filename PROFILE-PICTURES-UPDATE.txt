PROFILE PICTURE FIX

This version saves profile pictures to Supabase Storage.

Run ONLY:
supabase-update-safe.sql

This creates:
- profiles.avatar_url
- profile-pictures storage bucket
- storage policies for public read and authenticated upload

Do NOT run reset schema.

After running the safe SQL:
1. Upload this website to GitHub Pages root
2. Login
3. Go Profile
4. Choose image
5. Press Save Profile
6. It should say profile saved including profile picture
